# Rock&Stone

Сайт мастерской декоративных скал и кинодекораций.

- Сайт: https://proninpaul-afk.github.io/Rock/
- Основная страница: `index.html`. Стили и JavaScript находятся в этом же файле.
- Фотографии: `assets/portfolio/`.
- Публикация: GitHub Actions → `Deploy static content to Pages`, автоматически после изменений в `main`.

## Локальный просмотр

Из корня репозитория выполните `python -m http.server 8000` и откройте http://localhost:8000/.
Сборка и установка зависимостей не нужны.

## Контакты и заявки

Сайт предлагает переход в Telegram, Max, WhatsApp или звонок. Формы и автоматической отправки заявок нет. Чтобы проверить контакты, откройте каждую ссылку на телефоне и компьютере. Сообщение посетитель отправляет самостоятельно в выбранном приложении.

При смене номера или аккаунта найдите все вхождения старого значения в `index.html`, включая JSON-LD в начале файла. Сейчас используются `+79269406199`, `AKROBATYA` и ссылка Max в секции `#contact`.

## Публикация

После проверки изменений сделайте коммит и отправьте его в `main`. Во вкладке Actions дождитесь успешного завершения workflow. В публикацию попадают только `index.html` и изображения из `assets/portfolio/`; рабочие черновики и `uploads/` не включаются.

Внешняя зависимость страницы — Google Fonts. При недоступности шрифтов используются системные. Галерея, вопросы и ответы, просмотр фотографий и меню работают без сторонних JavaScript-библиотек.

## Продуктовая версия страницы

Страница перестроена вокруг решения о заказе: предложение → фотографии → ситуации клиента → согласование → бюджет → процесс → мастерская → отзывы → вопросы → обращение по фото.

Кнопка копирования вопросов заполняет только буфер обмена; сообщения автоматически не отправляются. Площадь, цена и результат конкретного объекта не приписываются фотографиям без подтверждения. Следующий этап — собрать реальные кейсы и заменить описательную галерею историями клиентов. Отзывы-заглушки сохранены по ранее согласованному решению.
